# Python Libraries

A beginner-friendly collection of notes, code examples and practical implementations of essential Python libraries used in Data Science, Data Analytics and Machine Learning.

## Libraries Covered

### 1. NumPy
- Numerical computing
- Array manipulation
- Mathematical operations
- Indexing and slicing

### 2. Pandas
- Data manipulation and analysis
- Series and DataFrames
- Data cleaning
- Handling missing values
- Data filtering and grouping

### 3. Matplotlib
- Data visualization
- Line plots and bar charts
- Histograms and scatter plots
- Plot customization

### 4. Seaborn
- Statistical data visualization
- Heatmaps
- Pairplots
- Boxplots and countplots
- Correlation analysis

## Objectives
- Understand the fundamentals of Python libraries.
- Practise concepts through code examples.
- Develop data analysis and visualization skills.
- Build a strong foundation for Machine Learning and AI.
